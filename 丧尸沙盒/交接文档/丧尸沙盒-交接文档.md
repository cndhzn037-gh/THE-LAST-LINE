## 一、项目速览

| 项 | 内容 |
|---|---|
| 名称 | 丧尸沙盒（内部也叫"丧尸沙盘"） |
| 类型 | 俯视角丧尸生存沙盒，浏览器端运行，可离线 |
| 形态 | **单文件 HTML**，`丧尸沙盒.html`，约 1.19 MB |
| 版本 | 3.0.1（2026-11-15，实验分支全量合并，正式版） |
| 语言 | 原生 JavaScript，无框架、无构建步骤 |
| 渲染 | Canvas 2D |
| 部署 | Cloudflare Pages（静态托管 + Service Worker 离线缓存） |
| 联机 | WebRTC 点对点 + 自建信令 Worker（实验性，未完成） |

**核心设计取向**：玩家负责**投放与调度**，而不是逐个操作单位。单位由 AI 自主作战，玩家决定往哪里投什么兵、花多少钱、什么时候接管。

## 三、技术架构

### 3.1 单文件结构

全部代码在 `丧尸沙盒.html` 的 `<script>` 内，24021 行。顶部用 `/* --- 分节标题 --- */` 的注释划分模块，实测可识别的主要分节包括：

| 分节 | 作用 |
|---|---|
| 纯净模式（H） | 只留战况读数，按钮全藏 |
| 顶部菜单弹层 | 主界面只留暂停/速度/菜单三项 |
| 首屏 | 开局面板，细节收进下一层 |
| 更新公告 | 整块盖在开局面板上，内容区自滚动 |
| 联机面板 | 房间号输入、连接状态 |
| 新手引导 | 开局后浮在底栏上方，五步流程 |
| 兵种数据 | 各单位属性、速度、恐惧半径、后坐力 |
| 舔舐者 / 自爆丧尸 / 医疗兵 | 各兵种的独立参数块 |

### 3.2 全局对象

代码里能确认存在的四个顶层模块变量：

```js
var CFG = {...}    // 全部可调参数，集中在一个对象里
var NET = {...}    // 联机通信
var LOCK = {...}   // 锁步同步（已放弃，保留代码）
var SNET = {...}   // 信令连接
```

**参数集中在 `CFG` 是这套代码最重要的可维护性设计**——调平衡只改一处，不用满文件找魔数。

### 3.3 模拟循环

- 固定步长模拟，五档倍速（0.25× / 0.75× / 1× / 2× / 4×，按钮循环切换）；倍速改变的是每帧推进的模拟步数，不是改 `dt`
- 暂停时不推进模拟
- 战争迷雾是独立开关（默认关），只影响玩家可见性，不影响 AI 判断

## 四、玩法与系统

### 4.1 六种模式

| 模式 | 核心规则 |
|---|---|
| **防线模式** | 丧尸从左侧持续涌入，人类守大本营自动作战，玩家负责投放调度 |
| **波次模式** | 按设定波数/首波延迟/间隔分批涌入侵，清空全部波次获胜（1.0.1 加入） |
| **混沌模式** | 丧尸三倍血量，子弹击退翻倍，平民大幅增加，开场有准备倒计时（1.0.1） |
| **护送模式** | 小队从右端出发，穿过休眠尸群，解救被封锁的平民并带回撤离点（1.0.2） |
| **剧情模式** | 有独立入口（1.3.0 从快捷键提升为菜单项） |
| **操控模式** | 玩家直接接管某个单位，改由键鼠/虚拟摇杆控制 |

### 4.2 关键系统

**寻路**：八方向 A*，带权重让路径更直；每帧限流，避免大批单位同时算路径造成卡顿。

**集群同步**：每只丧尸观察身边同类的移动方向，整体呈现潮水感而非散沙。

**护卫编组**：平民自动跟随最近的武装单位，站在护卫背对敌人的一侧。

**掩体利用**：武装单位主动寻找矮墙和墙角，站在掩体后射击。

**恐惧半径**：分兵种配置（武装 130 / 平民 260）。看到丧尸先拉开距离再打，不站着对射。夺回坚守点位途中恐惧半径缩到一半。

**后坐力**：每次开火沿射击反方向给射手一个速度增量，所以边退边打真的能退得更快。

**经济**：每秒自动增长 + 每击杀一笔赏金，所有单位有各自投放价。

**护送难度**：刷新量按“开局派出的武装单位数”乘数级缩放（基准 5 人，每多 1 人 ×1.18，封顶 12 倍），刷新间隔随兵力缩短（有上限）。中途补人不参与这个系数。

**存档**：手动存读 + 每 15 秒自动存档 + 存档导出/导入文件。

**地形编辑器**：拖拽框选、两角定位、单击放置三种画法；矩形吸附 8 像素网格；可画实心墙/矮墙/门/房屋/牢房/解锁门/出生点/撤离点/波次区/休眠尸群，也能直接摆单位。有撤销、清空、恢复默认。撒完房屋和短墙后会做连通性检查，自动拆掉压在死路上的障碍。

## 五、单位体系

### 5.1 人类阵营

| 单位 | 定位与特点 |
|---|---|
| **步枪兵** | 射速中等、伤害中等，基础主力 |
| **机枪兵** | 弹匣 100 发、高射速、子弹穿透 |
| **狙击手** | 射程无限、可穿一堵墙、对丧尸无限穿透。长时间开不了枪会主动找目标（等待时间 1.3.2 从 10 秒缩到 4 秒） |
| **盾兵** | 持盾挡在前排，护盾耐久可扛 6 秒接触，碎盾放冲击波推开周围丧尸。另有手枪（射程同速射、伤害 1） |
| **医疗兵** | 造价 100，体型/速度/寻路同平民，白色主体+绿十字。锁定被感染的己方单位（上限 4，装瞄具 5），读条 1 秒打出追踪治疗弹。治疗弹打丧尸按普通伤害算（每发 3 点）。升格英雄后弹匣扩到 3 倍（36 发）、锁定额度扩到 12 |
| **液氮兵**（1.3.3） | 造价 120，亮冰蓝，武器「液氮罐」。寻路同机枪兵，弹匣 1 瓶 / 换弹 3 秒。每秒 2 罐是弹匣未空时的峰值：初始 1 瓶打一发即换弹，扩容到 2~3 瓶才会体现。罐子不旋转、通体闪烁，走伪 3D 抛物线，撞地撞墙撞人即碎；碎处 0.12 秒铺满一个武装恐惧半径的寒冷圈（3 秒）：圈内先减速 30%，6 秒压到 95% 并裹冰壳，圈内每 1.5 秒 1 点伤害。离圈后按 3 秒基准回暖到正常速度。雪花只上下浮动、不绕圈心旋转。玩家操控时罐子抛向鼠标落点；与同伴分散落点。英雄：圈半径 ×5。平民英雄光环不补它的瓶 |
| **喷火兵**（1.3.3 起，1.3.6 定稿） | 造价 150，橙，武器「喷火器」。射程 560（机枪的 2/3），弹匣 100，每 0.1 秒耗 2 发，换弹 5 秒。喷出大量橙黄圆形火焰粒子（密度高，寿命按落点距离给，保证飞到火坑位置），喷口留一小段亮火；火焰落地后才留下圆形火片区，每 0.4 秒 2 点且可叠加（同一处多片火各算各的），并点燃 4 秒（每秒 1 点）。直流喷射 1 点/0.2 秒，DPS 与火坑相同；直流 + 火坑 + 点燃可同时结算。未升格时火焰被第一个敌方单位/墙挡住，只烧第一个；升格英雄后才无限穿透，被穿过者脚下留火。AI 按形态选择：敌人 ≤4 个或平均散布 >170px 时直射锁定，否则向尸潮质心带阻尼横扫；质心只计入有视线的敌人。平民英雄光环不补它的弹 |
| **磁爆兵**（1.3.3，1.3.4 平衡） | 造价 210，外圈深红、内芯深灰，武器「磁暴线圈」。弹匣 25，每 0.1 秒连打 5 发后冷却 1.5 秒，换弹 6 秒。单发 0.45（两轮 10 次打掉 4.5 血），定位是控场：命中附加麻痹（速度瞬间归零、黄白高频闪烁，时长同闪电；解麻后从静止重新起步）。闪电锁定与连锁都要求视线畅通，不能穿墙。连锁半径 174（130 的 +1/3），索敌范围 560（840 的 -1/3）。最多 10 个指标；20px 内抱团目标算 0.5 个。玩家操控时左键指定落点，落点在地板上时指标 +1；与同伴分散目标。英雄：指标 ×5。减散布配件改为加指标上限 |
| **激光兵**（1.3.3 起，1.3.6 定稿） | 造价 250，青绿，武器「镭射核心」。蓄力 2 秒（整段只放三圈蓄力环，环半径 = 射程 1/3、透明度 30%）后发射光柱：宽度 16（一整个单位直径），出膛过渡仅半个身位，末端按距离淡出；撞墙时精确截断，亮点周围 72 像素内造成小范围灼伤，特效为与出膛十字同规格的锥形火花。横扫 54°、一轮 2.8 秒，命中每 0.1 秒 1.5 点；一轮歇 0.5 秒，4 轮后冷却 6 秒。敌人 ≤4 个或平均散布 >170px 时改为直射锁定，直射同样积累热量、满 8 秒强制换弹；直射换目标有 2.2 弧度/秒转向阻尼。目标躲到墙后时立即停止照射。没有视线不蓄力，先侧移找视线。玩家操控时按住持续照射、移速惩罚 50%，松手清空这一发、退电池、3 秒换弹；连续照射 8 秒光柱由青绿转黄、橙、红，满红强制换弹。撞墙处有圆形柔光罩住锥形火花，英雄的火花与溅射半径等比放大。英雄：长度 ×3、宽度 ×5，出膛十字等比放大。减散布配件改为加光束宽度 |
| **平民** | 需要保护的对象，自动跟随护卫 |

### 5.2 丧尸阵营

| 单位 | 定位与特点 |
|---|---|
| **普通丧尸** | 基础兵 |
| **奔跑者** | 速度是普通丧尸两倍，但只有 3 点血，一梭子放倒 |
| **母体** | 血厚，每掉一定比例的血就地生崽 |
| **舔舐者** | 远处读条 2 秒伸舌头把人拽过来。舌头 30 血可被打断，断后冷却 4 秒。同一目标同时只挂一条舌头，其余排队 |
| **自爆丧尸** | 体型速度介于母体与普通之间。血量归零后原地蓄爆 1 秒（闪烁加快、体型膨胀到 2 倍），期间免疫伤害，然后炸开。冲击波半径 = 平民恐惧范围直径（520），波及人类减速 80% 持续 1 秒 |

### 5.3 军需商城（1.1.0）

快捷键 `Z` 或菜单开启。**不需要先接管单位**也能给它配装备。

- **枪口**：制退器（降后坐力）、收束器（收窄散布）、延展器（提升威力）
- **弹匣**：扩容 15 发、弹鼓 45 发、快速换弹（-45%）、复合型（扩容+提速）。**是增量不是改设定值**，装上不会让机枪兵弹容量反而变少
- **瞄具**：红点、快速，各自换准星样式，散布收窄 10%
- **防护服**：四级，分别扛 2/4/8/12 秒丧尸接触
- **移速强化**：两档（+10% / +30%），同槽位二选一
- **帝皇赐福**：当场升格为英雄，附带光环和额外武器

同一槽位只装一件，对已装项再点一次就是卸下。**装备只在页面刷新前有效，不上传、不进存档**（这是当前设计，不是 bug）。

1.3.3 的四个兵种对配件有自己的换算，面板上的数值会实时变：

| 配件 | 普通枪械 | 液氮兵 | 磁爆兵 | 激光兵 |
|---|---|---|---|---|
| 弹匣扩容 | +15 发 | +1 瓶 | +15 发 | 不生效（无弹匣） |
| 弹鼓 | +45 发 | +2 瓶（封顶 3） | +45 发 | 不生效 |
| 减散布 | 散布 × 系数 | 正常压散布 | 连锁指标 +2~+5 | 光束宽度 +5%~+30% |

## 七、联机系统（重要，含失败经验）

> 详细报告见 `联机功能报告.md`，这里提炼要点。

### 7.1 当前状态

| 环节 | 状态 |
|---|---|
| 房间信令 | ✅ 可用（四位数字房号） |
| 点对点直连 | ✅ 可用（数据不经服务器） |
| 世界状态同步 | 🟡 单向（房主 100ms 全量广播，成员跟随） |
| 操作指令回传 | ❌ 未完成 |
| 断线重连 | 🟡 仅恢复连接，不恢复战况 |

实测环境：电脑 Firefox + 手机 Via，ICE 从 checking 到 connected 约 1 秒。

### 7.2 为什么放弃锁步（关键经验）

锁步只需传输入、带宽极小，本是首选。前期验证过：同一环境下两个实例用相同种子跑 120 秒、上千单位，结果逐位一致。

**但真实环境测试发现**：两端分别跑在 Firefox（SpiderMonkey）和 Android WebView（V8）上时，**浮点超越函数存在末位差异**。差异每帧极小，但持续累积，数十秒后世界状态出现可见分歧且不可逆。

锁步要求两端结果完全一致，跨引擎环境下这个前提不成立 —— **这是踩过的坑，新对话不要重复尝试纯锁步方案**。

> ⚠ 注意：`signal/README.md` 的「下一步」一节还写着「确定性锁步：输入按帧广播，两端各自推进……所以锁步路线可行」，那是早期结论。该路线已在跨引擎测试中证伪，以本节和 `联机功能报告.md` 为准。

### 7.3 最终选型：房主权威

```
房主：跑完整模拟，每 100ms 广播全场状态，接收成员操作
成员：接收状态、渲染画面、回传自己的操作
```

优点：判定有唯一权威，不会出现"他看到我死了、我看到我还活着"。

### 7.4 后续待做（按优先级）

1. 操作指令回传
2. 本地预测与校正（消除操作延迟感）
3. 增量编码（只传变化的单位）
4. 压缩与量化
5. 插值渲染（不是按比例牵引）

以上都是常规工程实现，**方向已定，缺的是工作量**，不需要架构调整。

### 7.5 已知问题

- 成员端单位移动有"追随感"（按比例牵引而非插值）
- 尸潮涌入时带宽压力显著上升
- 部分浏览器默认禁用 WebRTC 本地候选收集，需手动改配置
- 断线重连不恢复战况

### 8.1 平台

### 8.2 产物

`deploy/` 目录即可上传的完整站点：`index.html`（主程序副本）、`sw.js`、`manifest.json`、两个图标、`rtc.html`、`_worker.js`。

`更新部署包.bat` 的实际行为（2026-11-06 修正并实测通过）：

1. 取根目录里除 `index.html` 外唯一的 `*.html`（即 `丧尸沙盒.html`），复制成 `deploy/index.html`
2. 复制 `sw.js`、`manifest.json`、`icon-192.png`、`icon-512.png`
3. 若存在，再复制 `signal/rtc.html`、`signal/_worker.js`

它**不会打包成 zip**，跑完直接把整个 `deploy` 文件夹拖进 Cloudflare Pages 即可。

> 旧版脚本只复制主程序和两个图标，导致 `deploy/sw.js`、`deploy/manifest.json` 长期与根目录脱节，这是 2026-11-06 对齐时修掉的一处。

### 8.3 Service Worker 注意事项

`sw.js` 是**网络优先**（不是缓存优先）：联网时每次请求先打服务器，成功后顺手更新缓存，断网才回退到缓存。所以**正常发布不需要改版本号**，重新上传后手机刷新一次就是新版。

缓存名固定为 `zombie-sandbox-v1`，`activate` 时会把其它名字的缓存清掉。只有确实出现"客户端一直吃旧缓存"时，才需要改这个缓存名强制失效。

**历史坑**：早期版本是缓存优先，必须手动改版本标记，否则永远读旧缓存。改成网络优先之后这条规矩就作废了——如果你看到哪里还写着"发布前必须改 sw.js 版本标记"，那是旧信息。

### 8.4 上传

Cloudflare 控制台 → Workers 和 Pages → 创建 → Pages → 上传资产，框架预设选"无"。

### 8.5 PWA

手机浏览器打开后"添加到主屏幕"即可离线启动。Service Worker 只在 http/https 下注册，本地双击 `index.html` 不会注册，不影响调试。

## 十、已知问题与踩过的坑

1. **跨引擎浮点不一致** —— 详见 7.2，决定放弃锁步。
2. **UI 居中排列在窄屏会把左边挤出屏幕** —— 居中布局内容溢出时左边滚动量是负值，手指划不回来。改法：从左边排起，不溢出时用两头自动外边距维持居中。
3. **手机整屏高度包含地址栏和工具栏** —— 按它算位置永远偏大，必须实测可视高度。
4. **兵种白名单式判断** —— 早期用硬编码名单，加新兵种时医疗兵/奔跑者/舔舐者/自爆丧尸都漏了，导致编辑器放不了、护送模式不撤离。改法：统一读兵种库。
5. **地图编辑器图层重叠导致死锁区域** —— 撒完房屋和短墙后要做连通性检查，拆掉压在死路上的障碍。
6. **状态同步的等待机制死锁** —— 帧号只在模拟推进时上报，等待时模拟不推进，双方互等。1.3.0 已修。
7. **暂停提示传染** —— 双方都上报暂停会互相传染。改法：按"是否真的被对方暂停"判断。
8. **操控状态卡死** —— 对局结束时若处于操控状态，手机没退出键只能刷新页面。现在结算时主动放开操控。

## 十五、接手记录（2026-11-07，1.3.3 四个新兵种）

### 15.1 读下来的设计取向

1. **玩家是调度者，不是操作者**：投放、编组、花钱、下令，具体战斗交给 AI。
2. **参数只准待在 `CFG` 里**：调平衡只改一处，不许在逻辑里写魔数。
3. **模拟必须可复现**：种子驱动、存档写全精度，读档要回到“那一刻”。
4. **单文件、零依赖、能离线**：产品约束，不是技术债。
5. **踩过的坑写进注释**：窄屏、白名单、跨引擎浮点、暂停传染，代码里到处是“为什么不能这样写”。
6. **表现服务可读性**：颜色先拉开、特效分层、持续开火按伤害频率抖（见《创作准则》§5.3）。

- **穿墙**：激光与磁爆都不再穿墙（光柱精确求交截断；闪电锁定与连锁都要求视线畅通）。
- **喷火**：主视觉改为大量橙黄圆形火焰粒子，喷口只留短亮火；火墙改成圆形火片区叠成，沿墙面与被烧单位持续落火，不再画矩形、不再零星。
- **液氮**：罐子不再旋转，改闪烁警示光；寒冷圈 0.12 秒铺满。
- **护送难度**：刷新量按开局派出的武装数乘数级缩放（基准 5，每人 ×1.18，封顶 12 倍），间隔同步缩短（上限 2 倍）。
- 回归测试从 27 项扩到 42 项（新增墙体阻挡、麻痹、护送系数）。

### 15.6 1.3.5 下拉菜单配色修正（同日）

### 15.7 1.3.6 锁敌与火焰修正（同日）

- **喷火**：未升格不再穿透，火焰被第一个单位/墙挡住，只烧第一个，落火也在那儿；英雄才穿透。射程 840 → 560；粒子密度提高、飞行距离加长；火墙改为粒子落地后才铺开（延迟 0.04~0.9 秒）。
- **激光**：光柱宽度 16，出膛过渡半个身位；出膛十字改为四根锥形臂（源头粗、末端细、中心向外渐变、高频闪烁）；撞墙截面光放大一倍；没有视线不蓄力。
- **磁爆**：单发 0.45，两轮 10 次打掉 4.5 血。
- **液氮**：雪花不再绕圈心旋转。
- **统一锁敌**：机枪 / 喷火 / 磁爆 / 激光 在没有视线时侧移找视线，不再隔墙开火。
- **激光手感**：蓄力环半径缩到 1/3、透明度 30%，横扫放慢到一轮 2.8 秒；玩家按住照射、移速惩罚 50%，松手清空一发、退电池、3 秒换弹。
- **磁爆操控**：玩家左键指定落点放电，落点在地板上时指标 +1；与同伴分散目标。
- **喷火粒子**：寿命按落点距离给，保证飞到火坑位置。
- **分散目标**：液氮与磁爆同兵种之间优先打没被点名的敌人。
- 回归测试扩到 62 项（新增：分散目标、地板落电、玩家激光换弹）。

- **撞墙溅射**：激光亮点周围 72 像素内每 0.1 秒 0.6 伤害；撞墙画成锥形火花（源头粗、末端渐隐、闪烁）。
- **液氮**：6 秒才压到 95% 减速，不再是 3 秒冻死。
- **磁爆英雄**：连锁上限 ×5。
- **武器名**：液氮罐 / 喷火器 / 磁暴线圈 / 镭射核心（HUD 与市场面板显示）。

- **激光热度**：玩家连续照射 8 秒，光柱颜色青绿→黄→橙→红并强制换弹；停火按 4/秒降温。
- **撞墙光效**：落点先盖一层从中心向外渐隐的圆形柔光，再叠锥形火花；英雄时火花与溅射半径一起放大 1.35 倍。
- **光环黑名单**：平民英雄的无限弹药对喷火兵、液氮兵无效，也不给它们射速加成；其余武装兵种照常。

- **磁爆范围**：连锁半径 130 → 174，索敌 840 → 560。
- **直射/横扫**：喷火、激光在敌人 ≤4 个或平均散布 >170px 时直射，否则横扫；激光直射也会过热换弹。
- **火焰伤害**：火坑 2 点 / 0.4 秒且可叠加；新增直流 1 点 / 0.2 秒；点燃仍是 1 点 / 秒。
- **粒子流速**：1500~2300，飞到火坑位置前不会淡没。
- **隔墙停火**：激光直射/横扫在目标躲到墙后时立即收束；喷火横扫的质心不再计入墙后敌人。
- **转向阻尼**：激光直射换目标按 2.2 弧度/秒转向，不会瞬间甩枪。
- **帝皇特使空对象**：导演/剧本直接触发时 W.reinf 可能为 null，已在 beginApotheosis 里补齐默认对象。
- **错误提示条**：改为 pointer-events:none、只显示最新一条、6 秒自动收起，不再遮挡底栏。
