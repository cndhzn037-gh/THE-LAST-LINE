## 一、改参数改哪里

**全部集中在 `CFG` 对象**（`丧尸沙盒.html` 内）。不要满文件找魔数，先搜 `CFG`。

已经确认存在独立参数块的子系统：

| 子系统 | 参数块内容 |
|---|---|
| 速度 | 全局速度比例、最高速、加速度、制动加速度、巡航倍率 |
| 恐惧半径 | 武装 130 / 平民 260，可按兵种覆盖 |
| 后坐力 | 按兵种覆盖 |
| 舔舐者 | 舌头血量 30、读条 2s、起手距离 = 平民恐惧×5、断线冷却 4s、拖拽倍率、舌头粗细 |
| 自爆丧尸 | 蓄爆 1s、最大体型 2 倍、冲击波半径 520、减速 80%/1s、血块数量 |
| 医疗兵 | 锁定半径、上限 4（瞄具 5）、读条 1s、治疗弹伤害 3 |
| 商城 | 各槽位装备的价格与效果 |
| 液氮兵 | `CFG.cryo`：投掷速度、抛物线重力、圈半径、冻结时长、伤害间隔、英雄倍率 |
| 喷火兵 | `CFG.flame`：射程、张角、弹药消耗、火墙伤害/间隔、点燃时长、扫射阻尼 |
| 磁爆兵 | `CFG.tesla`：弹匣、连发数、冷却、连锁半径、指标上限、抱团判定 |
| 激光兵 | `CFG.laser`：蓄力、光束长度/宽度、横扫角度、每 0.1 秒伤害、冷却轮数 |

## 二、常见改动对应位置

| 想改什么 | 搜什么 |
|---|---|
| 加新兵种 | `兵种库`——所有"有哪些兵种"的判断都读这里，加完不用逐处改 |
| 改菜单结构 | 搜"顶部菜单弹层" |
| 改新手引导 | 搜"新手引导" |
| 改版本公告 | HTML 里的 `PATCH_VERSIONS` + `GAME_VERSION`（`更新公告.txt` 只是副本） |
| 改地形预设 | 搜地图名（城镇/平原/室内/H 型通道） |
| 改联机 | `NET` / `SNET`（`LOCK` 是已废弃的锁步实现） |
| 加新兵种 | 先翻《创作准则》§2.3 的 14 项清单；开火分支搜 `newKindCombat` |
| 改新兵种开火 | 搜 `cryoThrowAt` / `flameCombat` / `teslaZap` / `laserCombat` |
| 改新兵种特效 | 搜 `drawCryoFields` / `drawFlameWalls` / `drawTeslaArcs` / `drawLaserBeams` |
| 改持续开火震动 | `CFG.shake` 的 flame / laser 两项；规则见《创作准则》§5.3 |
| 改护送难度 | `CFG.escort.armedBase / armedGrowth / armedScaleMax`；规则见《创作准则》§4.8 |

## 三、版本号在哪

`丧尸沙盒.html` 里：

```js
var GAME_VERSION = "2.9.88.1a";
```

另外几处相关：

- `sw.js` 的缓存名（`zombie-sandbox-v1`）—— 网络优先策略下**一般不用改**，只有确认客户端吃到旧缓存时才改它强制失效
- `历代更新.txt` + HTML 里的 `PATCH_VERSIONS` 公告 —— 这两处要一起改
- `更新公告.txt` 是 `PATCH_VERSIONS` 的纯文本副本，改公告先改 HTML 再同步它，别反过来

## 五、历史高发 Bug 区域

改这些地方时格外小心：

1. **窄屏 UI** —— 居中布局溢出、整屏高度含地址栏，已经修过好几轮
2. **兵种名单** —— 历史上用硬编码白名单，加兵种必漏，现在统一读兵种库，别再写死
3. **地图编辑器连通性** —— 图层重叠会造出死锁区域，撒完障碍要做连通性检查
4. **联机同步** —— 等待机制和暂停状态都有过死锁/传染，改动前先读 `联机功能报告.md`
5. **操控状态** —— 结算时没放开操控会卡死手机端
6. **存档结构** —— 只加字段不改下标，老存档必须能读；改完跑 `dev/newunits.mjs` 的存档用例
7. **持续开火** —— 别按帧抖屏、别每帧重建火墙/寒冷圈对象，照《创作准则》§5.3、§2.5 来

## 六、不要做的事

- ❌ 不要重新尝试纯锁步联机 —— 跨引擎浮点末位差异已证伪，见完整文档 7.2
- ❌ 不要把 API 密钥 / 账户密钥写进代码或文档
- ❌ 不要在没有验证的情况下改 `LOCK` 模块 —— 它是废弃代码，改它不会让联机变好
- ❌ 不要手改 `deploy/` 里的文件 —— 它是产物，以根目录和 `signal/` 为源，跑 `更新部署包.bat` 生成
- ❌ 不要先改 `更新公告.txt` —— 源头是 HTML 里的 `PATCH_VERSIONS`，这份 txt 只是同步出来的副本
- ❌ 不要新增兵种却不登记 —— 照《创作准则》§2.3 的 14 项清单走，漏一项就会在某个入口消失
- ❌ 不要在逻辑里写魔数 —— 新数值先加进 CFG 对应块，再引用
