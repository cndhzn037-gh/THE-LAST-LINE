# 09 发布检查

> 每个小版本正式发布前跑一遍。任一项失败即停止发布。

## 一、自动检查

```powershell
node dev/selftest.mjs 丧尸沙盒.html
node dev/newunits.mjs 丧尸沙盒.html
node dev/regression.mjs
node dev/stress.mjs 丧尸沙盒.html
```

`regression.mjs` 校验：

- 主程序 `GAME_VERSION` 存在
- 游戏内公告、历代更新、更新公告三处版本一致
- 交接文档包含当前版本
- `deploy/index.html` 与主程序 SHA-256 完全一致
- 压力测试：260 丧尸 + 10 人类，平均每步不超过 25ms
- 新系统存档往返：地块、区域、刷怪点、据点完整保留
- 设置面板无死循环：音量源滑块移出/放回 + 200 次防护
- 演示关闭：Esc/点空白/返回主页都会停 RAF 与市场预览
- 暂停：空格只冻结，不自动弹面板
- 点阵：32px 填充/擦除断言
- 首页/开战空白点击不关闭
- 手机横屏顶/底栏单行
- 面板冒烟：设置/帮助/快捷键（键鼠+触屏）/地图分析/暂停/结算/快速开始/新手引导共 9 项

## 二、构建

```powershell
更新部署包.bat
```

确认输出：

- 主程序 + sw.js + manifest + 图标 + 联机页均已同步
- `deploy/index.html` 哈希与主程序一致

## 三、发布包

- `signal/zangbishahe-with-signal.zip` 必须包含 `_worker.js` 与 `rtc.html`
- 压缩包内 `index.html` 哈希与主程序一致

## 四、手机实测

- 844×390 横屏：首页、开战设置、暂停、结算、设置、帮助
- 所有可点区域不小于 44px
- 底栏与安全区不重叠

## 五、回滚

- 保留上一版 `deploy/` 与 zip
- 正式版建立 `丧尸沙盒/回滚锚点/<版本>/`
- 回滚后重新跑 `regression.mjs`
