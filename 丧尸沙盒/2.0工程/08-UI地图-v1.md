# 08 UI 地图 v1（2.1.01）

> 目的：在改界面之前，先把"有哪些界面、从哪进、怎么回、每层放什么"画清楚。
> 设计方向：**战术沙盘终端**——近黑底、琥珀主色、冷青数据色、2px 直角、1px 细线、左侧色条。
> 不沿用 Outbreak 的蓝色圆角卡片；只学它的信息层级、触控尺寸与状态管理。

## 二、每一层放什么

### 第一层：首页
只回答三件事：**这是什么、从哪开始、还能去哪**。
- 标题 + 一句说明
- 三个模式（编号 01/02/03 + 一句差异）
- 主按钮：直接开打；次按钮：读取存档
- 底部：设置、玩法说明、版本号

### 第二层：开战设置
所有"会影响这一局"的参数，按组：
- 模式
- 敌情（丧尸规模/波次/支援）
- 我方（人口/英雄模式/岗位）
- 地图（编辑地形）
- 开始/恢复默认/返回

### 第三层：战斗内
- 顶栏只放"随时要用"的：状态、暂停、速度、菜单
- 底栏只放"投放与接管"：放置、操控、批量、尸潮、投放、赐福
- 其它全部进 ☰ 菜单，菜单按 战局/存档/行动/系统 分组
- 编辑器与导演是独立工作台，不与战斗底栏混排

## 三、我们自己的视觉规则

| 项 | 规则 |
|---|---|
| 底色 | `#080b0e`（近黑） |
| 面板 | `#0f151a` / `#141d24` |
| 主色 | 琥珀 `#d9a441`（标题、分区线、选中） |
| 数据色 | 冷青 `#6fc7c0`（数值、资源、状态） |
| 危险 | `#d95656`；成功 `#79b86b` |
| 圆角 | 2px（接近直角） |
| 线 | 1px `#2b3944`；选中时左侧 3px 琥珀条 |
| 字 | 系统无衬线；标签 10.5px/字距 2px；数值等宽 |
| 触控 | 粗指针下按钮 ≥44px；菜单行 ≥44px |
| 动效 | 只做 120ms 透明度/位移，不做弹跳 |

**与 Outbreak 的区别**：他们是蓝色圆角卡片 + 居中大按钮；我们是近黑终端 + 琥珀分区线 +
左对齐列表 + 编号模式行。信息层级相同，视觉语言不同。
