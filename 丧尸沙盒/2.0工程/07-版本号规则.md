# 07 版本号规则（修正版）

> 版本号服务于“工程区块”，不是给每个细节发新版本。
> 细节变动靠 Alpha 轮次记录，只有换方向才动小版本，只有换区块才动大版本。

## 格式

```
2 . 4 . 01 . 3 a
│   │    │    │  └─ Alpha 轮次（a=alpha, b=beta, rc=候选, 无=正式）
│   │    │    └──── 同一小版本内的第几轮构建
│   │    └───────── 小版本（两位，01–99）：同一区块内的方向/子批次
│   └────────────── 大版本（区块）：UI、兵种、演示、地图……
└────────────────── 特大版本：全盘重写才动
```

## 什么时候动哪一位

| 变动 | 动的位 | 例子 |
|---|---|---|
| 同一方向上的细节修正、文案、数值、小修小补 | **只动 Alpha 轮次** | `2.4.01.1a` → `2.4.01.2a` |
| 同一区块内换了一个方向/子功能 | 小版本 +1，Alpha 归 1 | `2.4.01.3a` → `2.4.02.1a` |
| 一个区块做完，进入下一个区块 | 大版本 +1，小版本归 01 | `2.4.03` → `2.5.01.1a` |
| 全盘重写 | 特大版本 +1 | `2.x` → `3.0.01.1a` |

**禁止**：改一个按钮、调一次数值就跳第二位或第三位。

## 阶段

- `a`：Alpha，自己/小范围测试，允许明显问题。
- `b`：Beta，功能完整，玩家可试。
- `rc`：只修 Bug，不加功能。
- 无后缀：正式版，写历代更新、建回滚锚点。

## 各处记录粒度

| 位置 | 粒度 |
|---|---|
| `GAME_VERSION` | 每个 Alpha 轮次都更新 |
| `PATCH_VERSIONS` | 每个小版本一条，合并该小版本下的多轮 Alpha |
| `更新公告.txt` | 每个小版本 |
| `历代更新.txt` | 每个正式版（无后缀） |
| `02-工程日志.md` | 每个 Alpha 轮次 |
| 回滚锚点 | 每个小版本正式版 |
