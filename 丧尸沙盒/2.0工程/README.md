## 使用规则

1. **先查 01 节点表，再动手**：任何开发都应对应一个节点编号；没有编号就先补节点。
2. **每次收工必须写 02 工程日志**：做了什么、改了什么文件、测试结果、下一步。
3. **节点状态只有五种**：`todo` / `doing` / `done` / `blocked` / `dropped`；`blocked` 必须写清原因，`dropped` 必须写清"为什么不做"。
4. **每个版本发布前**：更新 01 状态 → 写日志 → 按 1.x 规则升版本、写公告、建回滚锚点。
5. **中断恢复**：读 README → 00 看阶段 → 01 找 `doing` 和最近的 `todo` → 02 看最后一条日志。
