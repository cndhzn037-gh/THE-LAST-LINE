# 06 UI 全量清单：UI 不是"开始界面"，是整个游戏

> 结论先说：Outbreak 的 UI 覆盖 **16 个界面/面板 + 8 类通用组件**，从选图、选波、编队、
> 单位编辑、地图编辑、地砖编辑、波次编辑、敌人生成权重，到暂停、结算、升级三选一、存档转移。
> 我们的 2.1 如果只改"主菜单"，等于没做。本文先把全貌列清，再拆子批次。

---

## 一、Outbreak 的 UI 全貌

### 1. 主菜单（`js/ui/menu.js`）

| 区块 | 内容 |
|---|---|
| 顶部 | 标题、QQ 群（点击复制） |
| 左/中 | 地图选择卡（内置/自定义、尺寸、改名、删除）、波次选择卡（内置/自定义、∞ 无尽、改名、删除）、无尽开关、开始按钮 |
| 右侧 | "其他模式"两张卡：俯视射击（无限地图/尸潮/升级三选一）、操控模式（亲手操控一个单位） |
| 底部 | 三个编辑器入口：地图编辑器、单位编辑器、波次编辑器 |
| 其他 | 显示设置、存档转移 |

### 2. 显示设置（`menu-settings.js`）

引导与提示、血条、射程、索敌线、据点、窄巷、守卫位、镜头自动追踪、触感振动、
人类增援、空白波次、自动识别房屋/窄巷等开关；改动立即保存。

### 3. 存档转移（`save-transfer.js`）

导出 JSON、系统分享、存档码（OB1Z，deflate+base64url）、导入文件/粘贴/剪贴板、
状态提示、错误校验。

### 4. 俯视开局（`tdscreen.js`）

分步：① 选择角色（列表 + 生命/伤害/射速/移速/射程/弹速/穿透/子弹数预览）
② 地图种子（输入/随机）③ 头顶文字、地图、波次、属性预览、开始/取消。

### 5. 敌人生成配置（`tdscreen.js` + 权重编辑器）

每类丧尸/人类敌人的权重、上限、解锁条件、弹药/换弹；恢复默认；关闭并保存。

### 6. 操控开局（`control.js` + `tdscreen.js`）

选角色、头顶文字、地图、波次、开始。

### 7. 单位编辑器（`unit-editor.js`，1864 行）

- 左：人类/丧尸列表、+新建、复制、删除、还原默认。
- 右：名字、阵营、大小、血量、移速、加速度、特殊机制（无/医疗/盾/友军增益/喷火）、
  伤害、减速、回血、护盾、近战、自爆、喷吐、突进、子弹速度/射程/数量/散布/穿透/暴击、
  换弹/弹匣/过热、行为模式、颜色。
- 顶：实机演示（真实 AI/弹道/换弹/过热/护盾/爆炸/增益/减速 + `drawWorld`）。
- 颜色：Canvas HSV 取色板（色相/饱和/明度/色号/常用色/恢复原色）。

### 8. 地图编辑器（`map-editor.js`，2060 行）

- 三个标签：地形 / 单位 / 地砖。
- 工具：笔、画线、方框、矩形、填充、擦除、移动画布。
- 地图：坐标尺、中心轴、十字定位线、坐标读数；缩放 5×~40×；拖到边缘自动平移。
- 单位：分类（全部/人类/丧尸）、翻页、批量放置。
- 地砖：地砖库、地砖编辑器、新建/编辑/改名。
- 拼接：组名、横纵张数、整组预览、跨块编辑。
- 操作：撤销（40 步）、清空、测试、保存、另存为、返回。

### 9. 地砖编辑器（`tile-editor.js`）

外观（颜色/花纹/边缘/透明度）、通行（人类/丧尸/子弹）、踩踏效果（减速/秒伤）、
结构（可破坏/血量/合并血量）。

### 10. 波次编辑器（`wave-editor.js`）

波次列表、每波出场单位与数量、生成点、波次间隔、无尽起始/增长、
测试、保存/另存为/重命名。**这就是"每一波出现什么僵尸"的 UI。**

### 11. 拼接面板（`stitch-panel.js`）

组名、横向/纵向张数、槽位、整组尺寸、跨图编辑。

### 12. 暂停面板（`pause.js`）

继续、重开、设置、回主菜单。

### 13. 结算/失败面板

胜负原因、重开、返回。

### 14. 游戏内 HUD（`hud.js` + `render/world.js`）

血条、弹药、波次、资源、目标、提示、触屏按钮。

### 15. 俯视升级三选一 + 触摸面板（`modes/topdown/ui.js`）

升级卡池、暂停、结算、触摸摇杆/按钮。

### 16. 通用组件

toast（去重/限 3 条/2.6s）、黑场过渡（0.22s）、弹层缓动、确认框、
命名输入框（`promptText`，不用原生 prompt）、取色板、触控命中区扩张（40px）。

## 二、我们的 UI 现状

| 区域 | 现有内容 |
|---|---|
| 顶栏 | 状态读数、暂停、速度、☰ 菜单 |
| 菜单弹层 | 存档/读档、导出/导入/存档码、重开、装备市场、联机、开火模式、剧情模式、设置与画面、帮助与其他（音量/迷雾/播报/命中/音效/键位/恢复默认/调试/调参/公告） |
| 底栏 | 放置下拉（兵种/小队/工事）、操控、批量、尸潮、投放、赐福 |
| 地图编辑器 | 5 个标签（地形/单位/关卡要素/行进路线/其它）+ 工具 + 撤销/清空/恢复默认/完成 |
| 导演栏 | 移动/跟随/待命/坚守/朝向/射击/保险/对话/阵亡/解除/镜头/事件/导出/导入/键位/存档 |
| 画布 HUD | 资源、波次、剧情提示、引导、结算 |
| 覆盖层 | 主页、帮助、设置、手动存档、市场、公告、联机、存档码 |
| 通用 | toast、tips 引导、更新公告 |

**特点**：功能不少，但**入口层级深、命名偏内部术语、样式不统一、手机命中区不足、没有 UI 地图**。

## 四、2.1 拆成四个子批次

版本号规则见 `07-版本号规则.md`。2.1 不再是一个大版本，而是：

| 子批次 | 版本示例 | 主题 | 交付 | 验收 |
|---|---|---|---|---|
| 2.1.01 | `2.1.01.1a` | 清单 + 设计系统 + 主壳 | UI 地图、主题/控件、主菜单重排、40px 命中区 | 新玩家 30 秒说出每个入口作用 |
| 2.1.02 | `2.1.02.1a` | 游戏内 HUD/暂停/结算/设置 | 统一 HUD、暂停面板、结算面板、设置分区 | 手机 844×390 全可点 |
| 2.1.03 | `2.1.03.1a` | 编辑器族 | 地图/单位/波次/地砖/拼接的统一工作台外壳 | 5 分钟画出可玩图 |
| 2.1.04 | `2.1.04.1a` | 开局流程/引导/模式选择 | 分步开局、模式卡、首次引导、帮助术语 | 3 名新玩家独立完成一局 |

每个子批次内部：`a` alpha → `b` beta → `rc` 候选 → 正式。

## 五、UI 信息架构草案（三层）

**第一层：主界面**
- 继续游戏
- 开始新局（模式 → 地图 → 兵种/规则）
- 继续/读档
- 编辑器（地图/单位/波次/地砖）
- 设置（画面/操作/音频/调试）
- 帮助（术语/操作/更新公告）

**第二层：模式准备**
- 防守：选图 → 选波次 → 选兵种 → 开始
- 护送：选图 → 队伍 → 难度 → 开始
- 剧情/导演：选图 → 剧本 → 开始
- 操控：选人 → 头顶文字 → 开始

**第三层：编辑器工作台**
- 顶：标签（地形/单位/关卡/路线/其它）+ 撤销/清空/测试/保存
- 左：工具/素材库
- 中：画布 + 吸附开关 + 尺寸读数
- 右：属性面板
- 底：状态栏（坐标/缩放/选中对象）

## 六、风险

| 风险 | 缓解 |
|---|---|
| 入口迁移让老玩家找不到 | 保留旧布局开关一版；首次进入给"新布局"提示 |
| 编辑器族一次改太多 | 按 2.1.03 子批次，先外壳后细节 |
| 手机命中区扩张导致误触 | 40px 下限 + 相邻防重叠 + 视觉不变 |
| 版本号过细导致混乱 | 07 规则 + 日志只记 build，公告只记批次 |
